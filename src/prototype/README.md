# 拾样：Agent 工作台 UI 原型

这是用于比较交互布局的临时代码，不是正式产品实现。设计问题：以聊天为主的工作台，如何让用户顺畅查看产物并人工复核？

## 启动

首次安装依赖：`npm install`。

运行：`npm run prototype`。

打开 http://127.0.0.1:5173/prototype/workbench?variant=A 。

本原型使用浏览器呈现桌面布局，尚未接入 Electron 原生窗口、Agent、文件系统或模型服务。所有项目、会话及标注都为内存模拟数据，刷新后重置。正式应用仍按已确认的 Electron 架构实现。

## 三个方案

- A「安静分栏」：经典项目侧栏、主聊天区和停靠工作面板。
- B「对话画布」：聊天作为完整画布，右侧产物浮层独立展开。
- C「专注工作室」：紧凑深色导航，查看产物时给标注区域更多空间。

底部悬浮条与左右方向键切换方案，URL 使用 `variant=A`、`variant=B`、`variant=C`。输入框获得焦点时方向键保留编辑功能。生产构建隐藏设计切换条。

## 体验步骤

1. 左侧切换两个项目和项目内会话，或新建会话。
2. 在聊天中打开「候选标注已整理」，右侧出现人工复核标签。
3. 打开「原始图片」与「标注方案 v2」，体验多标签切换。
4. 修改题目或点选候选图片，点击「确认并下一张」。第一组模型建议故意漏选第五格，便于体验纠正过程。
5. 返回上一张确认修改仍在，收起面板返回聊天；切换项目、会话后再返回，查看原状态。
6. 发送一条消息体验模拟回复；设置页面仅说明两种模型的配置位置，不收集密钥。

图片由代码绘制的无品牌 SVG 果蔬和几何形状组成。没有试跑、批量启动或流程审批按钮。人工确认只改变模拟复核状态。

## 实现与来源

- React、TypeScript、Vite；Lucide 图标。
- shadcn/ui Button 原始组件来自 https://ui.shadcn.com/r/styles/new-york/button.json 。
- beUI Message 与关联依赖来自 https://beui.dev/r/message.json 。实际消息行与气泡使用这些组件，并通过 LocaleProvider 提供中文文案。
- 相关组件许可见 THIRD_PARTY_NOTICES.md。
- 原型采用内存状态和直接实现，暂不套用正式应用的模块拆分、ESLint 门槛或持久化设计。选定交互后应按正式标准重新实现。
