# 任务分类标签

工程 skills 使用以下五种标准角色。本表将角色映射到本仓库实际使用的 GitHub 标签。

| 标准角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已明确，可交给 Agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

skill 提到某种任务角色时，使用表中对应的 GitHub 标签。
如需沿用已有的其他标签名称，修改表中的“GitHub 标签”列。
